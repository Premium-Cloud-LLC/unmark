# Unmark

A free macOS menu bar utility that converts Markdown into formatted text on your clipboard. Built for the AI chatbot era — paste from ChatGPT, Claude, or Gemini, and copy beautifully formatted output into Mail, Pages, Notes, Slack, or anywhere else.

> **Markdown, perfectly pasted.**

[**Download for macOS →**](https://github.com/Premium-Cloud-LLC/unmark/releases/latest)

---

## What it does

1. Click the **U** icon in your menu bar
2. Paste any Markdown into the popover
3. Done — formatted text is already on your clipboard
4. Switch to your destination app and ⌘V

No dialogs. No buttons. No friction.

## Features

- 🚀 **Instant conversion** — sub-100ms, debounced as you type
- 📋 **Three output formats** — Rich Text (RTF + HTML), HTML only, or Plain Text
- 🔒 **100% local** — no servers, no analytics, no network access at all
- ⏱️ **Auto-clear** — input field clears 5 seconds after copy, with visible countdown
- 🌗 **Dark/light mode aware** — menu bar icon auto-tints
- 🪶 **Tiny footprint** — ~2 MB DMG, no background daemons

## Supported Markdown

CommonMark plus most GFM extensions:

- Headings (h1–h6)
- Bold, italic, bold-italic
- Inline code and fenced code blocks
- Bullet lists and numbered lists (including nested)
- Links
- Tables
- Blockquotes
- Horizontal rules

## System requirements

- macOS 13 Ventura or later
- Apple Silicon and Intel Macs supported

## Privacy

Unmark collects nothing. Ever. The app runs in Apple's App Sandbox with no network entitlement — even if we wanted to phone home, we couldn't. See [PRIVACY.md](docs/PRIVACY.md) for details.

## Building from source

### Prerequisites

- Xcode 15 or later
- [xcodegen](https://github.com/yonaskolb/XcodeGen) — `brew install xcodegen`

### Quick start

```bash
git clone https://github.com/Premium-Cloud-LLC/unmark.git
cd unmark
xcodegen generate
./run.sh
```

The `run.sh` script:
1. Builds the app via `xcodebuild`
2. Stops any running instance
3. Launches the freshly built app

The U icon appears in your menu bar. Click it to use.

### Distribution build

For producing a notarized DMG that can run on any Mac without Gatekeeper warnings:

```bash
./scripts/make-dmg.sh
```

Requires an Apple Developer account ($99/year), a Developer ID Application certificate installed in Keychain, and notarytool credentials configured. See [SHIP_CHECKLIST.md](docs/SHIP_CHECKLIST.md) for end-to-end instructions.

## Tech stack

- **Swift + SwiftUI** — modern declarative UI, macOS 13+
- **[Down](https://github.com/johnxnguyen/Down)** — fast Markdown parser (cmark-based)
- **AppKit** for clipboard operations and haptic feedback
- **SMAppService** for Launch at Login
